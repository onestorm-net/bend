# 0011: `ProtocolException` for wire input

**Status:** Accepted

## Context

Every malformed or oversized-input throw site in `protocol` (`ProtocolUtil`,
`VarInt28FrameDecoder`, `VarInt28LengthEncoder`, `PacketDecoder`; 12 sites) threw a bare
`IllegalArgumentException` marked `// todo change exception`. These sites sit on the untrusted
network path, so a peer can trigger them repeatedly on purpose; `fillInStackTrace()` walking the
stack on every throw is then a cheap way to burn CPU. Velocity avoids this with a shared static
exception instance, which forces a fixed message.

## Decision

- Malformed or oversized wire input raises
  `net.onestorm.bend.protocol.exception.ProtocolException`. It is one flat class.
- Caller misuse at protocol-definition time stays `IllegalArgumentException`
  (`AbstractProtocol.getPacketId` for an unregistered class, `registerPacket` with an
  out-of-range id).
- In the API modules, a call that the object's current state forbids raises
  `IllegalStateException`, while a bad argument stays `IllegalArgumentException`. The first case
  is registering an endpoint id already registered in that direction
  (BD-0003 [DECISIONS.md](/docs/issues/BD-0003-endpoint-registration-typed-handles/DECISIONS.md) D6).
- `ProtocolException` skips the stack trace by passing `writableStackTrace = false` (and
  `enableSuppression = false`) to the JDK's 4-argument `RuntimeException` constructor, so every
  throw keeps its own specific message.
- A static `debugStackTraces` flag turns stack traces back on for local development. It is off
  by default. Its accessors (`isDebugStackTraces()`, `setDebugStackTraces(boolean)`) are
  generated by Lombok on the static field. It is a plain static flag, not a system property.

## Does not decide

- Which module sets the debug flag from configuration. `protocol` has no configuration story;
  whichever module owns configuration calls the setter.
- A hierarchy of exception types. Split only when something downstream needs to catch failure
  kinds differently.

## Rejected

- Velocity's shared static exception instance: needs a static, non-specific message.
- A system property for the debug toggle: would give `protocol` a configuration-loading story
  it doesn't otherwise need.
- A category hierarchy now: nothing catches by kind yet.
